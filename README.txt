# HomeFix – Appliance & Electrical Service Website

## Run in VS Code

1. Extract this folder.
2. Open the folder in **Visual Studio Code**.
3. Open `index.html`.
4. Install the **Live Server** extension if you do not already have it.
5. Right-click `index.html` → **Open with Live Server**, or click **Go Live** in VS Code.
6. Your browser will open the website locally.

The Live Server extension supports local development with automatic browser reload when files change. See the VS Code Marketplace listing:
https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer

## Files

- `index.html` – website structure/content
- `style.css` – modern responsive design
- `script.js` – filters, booking form, menu and interactions

## Easy customization

Search in `index.html` and change:
- HomeFix → your business name
- +91 99999 99999 → your real phone number
- Madanapalle & nearby areas → your service area
- Service names/details → your exact services

The booking form is currently a front-end demo. It can later be connected to WhatsApp, PHP/MySQL, Firebase, or another backend.
